- **requirements:** SPEC §7 (`GET /api/takes` = takes for the session list), Q-008 clarified

## Context

Takes currently persist across browser refreshes even though the panel is labelled “This session”.
Make `/api/takes` session-scoped: the Studio sends a per-page-load session id (`X-Studio-Session`
header), takes record it, and the list only returns that session's takes. Disk retention stays
newest-50 globally; old takes remain stored but are not shown.

## Steps

1. `studio_takes.py`:
   - Helper `_session(request) -> str | None`: read `X-Studio-Session` (or `?session=`) and accept
     only `^[A-Za-z0-9_-]{1,64}$`; invalid → None.
   - `/api/speak` (save=true) stores the session in the take `extra` (`{"session": sid}`); streamed
     takes too.
   - `GET /api/takes`: if a session is present, filter to `take.get("session") == sid`; with no
     session (curl/API clients) keep returning all, as today. `kind` filter unchanged; design takes
     are not session-bound.
   - Do not change take ids, wave/audio/save-as-voice/delete routes.
2. Tests: same session sees only its takes; two sessions are isolated; no header returns all;
   invalid header treated as absent; streamed take carries the session; existing tests stay green.
3. Do not edit UI or store.

## Definition of done

- [ ] `verify:` green; output in `## Report`.
- [ ] A new page-load session starts with an empty takes list; old takes are still on disk.
