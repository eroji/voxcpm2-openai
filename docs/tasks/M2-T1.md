## Context

`app/importer.py` currently raises `NotImplementedError`. Implement
`import_qwen3_speakers(store, source_dir, *, overwrite=False)` per SPEC §5: copy every
`*.safetensors`, preserving the original audio tensor + `ref_text`, and add:
`language` (suffix of the name: `-en`→`en`, `-ja`→`ja`, `-kr`→`ko`, `-zh`→`zh`, else `""`) and
`source` (from existing `consent`: `own-generated-voice` → `designed`, otherwise `uploaded`).
Skip existing names unless `overwrite=True`; report `{"imported": [...], "skipped": [...],
"failed": [(name, error_message), ...]}`. Never abort the whole import for one corrupt file.

Use `VoiceStore.create(...)` so the store index/caches stay correct, passing the original
metadata through its `metadata=` argument (keeps `mime_type`, `original_filename`, `file_size`).
`consent` must be preserved; default to `uploaded-via-studio` if missing.

## Steps

1. `tests/test_importer.py` builds a source dir with safetensors written directly via
   `safetensors.numpy.save_file` (24 kHz float32 tone) for: `ashley-en`, `ashley-ja`, `ashley-kr`,
   `ashley-zh`, one file with `consent="own-generated-voice"`, one corrupt file, one invalid name.
   Assert languages (`ko` for `-kr`), source mapping, metadata preservation, `skipped` on a second
   run, `overwrite=True` replaces, corrupt/invalid entries land in `failed` and do not raise.
2. Implement with `safe_open(..., framework="numpy")` for metadata + tensor, `store.create(...)`,
   and `Result` returns as above.
3. Empty/missing `source_dir` → `{"imported": [], "skipped": [], "failed": []}` (no exception).
