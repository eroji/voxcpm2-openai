# M5-T4 — Align CI/CD with the `notely` house pattern

- **Milestone:** M5
- **Wave:** 9

- **deps:** M1-T13

- **requirements:** R-045, R-049, R-050, Q-015

## Context

The `notely` project (sibling repo) is the working reference for this GitLab instance:
`HARBOR_TOKEN` (not `HARBOR_PASSWORD`), `GIT_DEPTH: 0`, `DOCKER_TLS_CERTDIR: ""` with `docker:dind`,
builds on main + `vX.Y.Z` tags, deploy on tags only with a base64 SSH key and image pinned to the
tag, `docker login` on the target over stdin. Our frozen `deploy/compose.yaml` pins `:0.1.0`, so CD
needs an override file rather than editing it.

Actual STT URL (human, 2026-11-02): `http://vllm.dotslash.io:8890/v1`.

## Steps

1. `.gitlab-ci.yml`:
   - Use `HARBOR_TOKEN` everywhere (variables, login, docs comments).
   - `package` job: `GIT_DEPTH: 0`, `DOCKER_TLS_CERTDIR: ""`, rules
     `$CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH || $CI_COMMIT_TAG =~ /^v\d+\.\d+\.\d+/` plus
     `$HARBOR_USER`; keep `package:check` always-on.
   - Production image tag = `${CI_COMMIT_TAG#v}` for tags, `${CI_COMMIT_SHORT_SHA}` otherwise.
   - Deploy jobs: keep `DEPLOY_TARGET=staging|production` opt-in; staging on main, production on a
     `vX.Y.Z` tag + manual. Use the notely SSH pattern (base64 key → file, BatchMode,
     accept-new), `docker login --password-stdin` on the target, `docker compose -f
     deploy/compose.yaml -f deploy/compose.deploy.yaml pull/up -d` with `DEPLOY_IMAGE` exported.
     Default `DEPLOY_HOST: vllm.dotslash.io`, `DEPLOY_USER: deploy`,
     `DEPLOY_PATH: /opt/voxcpm2-openai`.
   - Production health gate: `curl -fsS http://127.0.0.1:8880/ready` after `up -d`.
2. `deploy/compose.deploy.yaml` (new override, reference compose untouched):
   `services.voxcpm2-openai.image: ${DEPLOY_IMAGE:?DEPLOY_IMAGE is required}`.
3. `docs/RUNBOOK.md`: update the CI-variable table (`HARBOR_USER`/`HARBOR_TOKEN`, `DEPLOY_SSH_KEY`,
   `DEPLOY_HOST`/`DEPLOY_USER`/`DEPLOY_PATH`), the exact `STT_URL` value, and the tag-release
   procedure (`git tag vX.Y.Z && git push --follow-tags`). Remove stale references to
   `HARBOR_PASSWORD` and to the unparametrised image caveat.
4. `tests/test_deploy.py`: assert the override file and its `${DEPLOY_IMAGE` placeholder; assert
   the CI file contains `HARBOR_TOKEN`, `GIT_DEPTH`, `DOCKER_TLS_CERTDIR: ""`, tag-only production
   rules, `compose.deploy.yaml`, and that `deploy/compose.yaml` is still byte-identical (hash pin
   stays). Add a test that the runbook contains the exact STT URL.
5. Do not edit `deploy/compose.yaml`, `deploy/voxcpm2-3090.yaml`, app code or tests outside
   `owns:`.
