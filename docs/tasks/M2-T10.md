### Mutation check (DoD item 2) — the test does guard the skip logic

`app/store.py` was **not** edited. The skip (`if path.stem != key: raise BadRequest` in
`_read_voice_file`) was removed only at runtime, by monkeypatching `app.store._read_voice_file`
with a variant that lowercases the stem instead of rejecting it:

```console
$ PYTHONPATH=/tmp/opencode .venv/bin/python -m pytest tests/test_store.py -q -p noskip_plugin -k uppercase
    assert store.list() == []
E   AssertionError: assert [Voice(key='a...'Ashley-en'})] == []
E     Left contains one more item: Voice(key='ashley-en', name='Ashley-en', ... path='.../voices/Ashley-en.safetensors')
FAILED tests/test_store.py::test_uppercase_hand_placed_file_is_invisible
```

Because that fails at the pre-existing first assertion, the rebuild path was checked separately
with the same runtime mutation:

```console
mutant rebuild list: ['ashley-en']
mutant rebuild index order/keys: ['ashley-en'] ['ashley-en']
=> new rebuild assertions fail under the mutation (as intended)
```

So with the skip logic deleted, both the new `rebuilt.list() == []` / `"ashley-en" not in
index["voices"]` assertions and the mirror-case `== ["ashley-en"]` (it would return two entries)
fail. The scratch plugin lived only in `/tmp/opencode` and has been deleted.
