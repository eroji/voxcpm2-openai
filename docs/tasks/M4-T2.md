## Context

`index.html` has the Design screen with `#design-desc`, `#design-tags`, `#design-lang`, `#design-n`,
`#design-sample`, `#generate-candidates`, `#candidates`, `#design-name`, `#save-designed`,
`#design-error`; `core.js` exports `api`, `state`, `loadVoices`, `play`, `renderWave`, `showError`,
`clearError`, `registerScreen`, `fmtDuration`.

## Steps

1. `registerScreen("design", { init, show })`: `init` binds tag buttons (append `, <tag>` to
   `#design-desc` without duplicating), generate, delegated candidate selection, save.
2. Generate: validate description/sample non-empty; disable button "Generating…"; POST
   `/api/design/candidates` with `{description, sample_text, language: #design-lang.value,
   n: + #design-n.value}`; render candidates into `#candidates`:
   - article `.vs-cand` with play button (`play(audio_url)`), `<svg class="vs-wave"
     viewBox="0 0 300 24" preserveAspectRatio="none"><path/></svg>` filled by GET `wave_url` amps,
     label "Candidate <index>" + `seed <seed>`, and a `.pick` button (`aria-pressed`).
   - click `.pick`: single selection; toggles `.is-selected` on the article, `aria-pressed` and
     "Selected"/"Select" text, `is-current` on that candidate's wave; clears others.
   - store `selectedCandidate` in module state; call `updateSaveState()`.
3. Save gating: name valid (`/^[a-z0-9][a-z0-9_-]{0,63}$/`, lowercased as typed, not already in
   `state.voices`) and a candidate selected → enable `#save-designed`.
4. Save: POST `/api/design/save` `{candidate_id, name, language}`; on success `loadVoices()`, show
   success text, reset selection/name; duplicates show the 409 message inline.
5. Empty candidates: keep the container empty. Errors inline via `showError("design", ...)`.
6. Use `textContent` for all server data.
