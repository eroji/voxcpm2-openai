## Context

The API-level suite cannot prove the UI works. Start the real app against `tests/fake_engine.py`,
drive it with Playwright (Chromium), and save screenshots for the lead's visual comparison against
`ui/studio.html` at 1280 px and 390 px.

## Steps

1. `tests/e2e/conftest.py`:
   - session fixture `live_app`: create a temp `Settings` with its own data dir (`tmp_path_factory`),
     `engine_url=fake_engine.url`; seed 3 voices through `VoiceStore` (`ashley-en`, `ashley-ja`,
     `ashley-ko`) before start; run `uvicorn.Server` on a free port in a thread; wait for `/health`;
     yield `base_url`; stop the server.
   - fixture `page`: `pytest.importorskip("playwright.sync_api")`; launch chromium
     (`headless=True`), new context `viewport={"width":1280,"height":900}`; yield page; close.
   - If Chromium is not installed, fail with a one-line instruction:
     `.venv/bin/playwright install chromium` — do **not** silently skip.
2. `tests/e2e/test_studio.py`:
   - Load `/`: title "Voice Studio"; 5 tabs; `aria-current="page"` on Speak; `#engine-status`
     eventually starts with "Ready" (poll ≤10 s).
   - Hash routing: click each tab, URL hash changes, matching `.vs-screen` visible, others hidden.
   - Speak: click `#generate`; button becomes disabled/"Generating…" then re-enables; a `.vs-take`
     appears in `#takes-list` with an SVG wave whose `path[d]` is non-empty; newest has
     `is-current`.
   - Voices: rows render from the API (3), language filter "Japanese" shows only `ashley-ja`,
     search filters, Edit reveals inputs, Cancel restores, Delete reveals the in-place confirm text.
   - Clone: `#save-voice` disabled until file+name+consent (set file via `set_input_files` with a
     generated 5 s WAV in `tmp_path`), invalid name shows the pattern text, consent enables.
   - Design: generate 2 candidates, select one, assert `aria-pressed`/`is-selected`, save with a
     unique name, assert success text and a new voice via `/api/voices`.
   - Engine: 8 `.vs-stat` blocks, warm-up button works, restart requires two clicks.
   - Keyboard: Tab from the top reaches the tabs, Enter activates, focus ring style is set.
   - Screenshots: `test-results/ui-<screen>-1280.png` for all five screens and
     `...-390.png` for Speak and Voices; compare visually in the lead review.
3. Keep the suite independent of execution order; reset fake-engine counters only where needed.
4. Do not edit application code. If a UI bug blocks the suite, report it as `BLOCKED: <file>:<line>`
   in the Report and mark the test `xfail` with the reason; the lead turns it into a fix task.
