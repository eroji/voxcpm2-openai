## Context

Wave-5 review found `/v1/models` lists only `voxcpm2` (SPEC §6/R-021 says plus aliases `tts-1`,
`openbmb/VoxCPM2`), `model` is optional although §6 says required, `X-Voice` uses a display name
that may be non-ASCII (Starlette headers are latin-1 → 500, and on the streaming path that 500 can
leak a slot), and unknown `/api`/405 responses use FastAPI's `{"detail": ...}` instead of the
OpenAI error shape.

## Steps

1. `app/models.py`: `SpeechRequest.model: str` (required, no default). Keep `extra="ignore"`.
2. `app/speech.py`: carry the lookup key alongside the display name:
   `ResolvedVoice.key: str | None`, and add `key` to `SpeechResult`/`StreamingSpeech`; set it from
   `voice.key` for stored voices, `None` for ad-hoc. Update construction sites and tests as needed.
3. `app/routers/v1.py`: `GET /v1/models` returns three cards (`voxcpm2`, `tts-1`,
   `openbmb/VoxCPM2`); `X-Voice` uses `seq.key or seq.voice` (ASCII);
   streaming header uses the same. Keep streaming aclose/background.
4. `app/main.py`: add exception handlers so 404/405 (Starlette `HTTPException`) return
   `{"error": {"message", "type", "param", "code"}}` — map 404 `not_found`, 405
   `method_not_allowed` — for both `/v1` and `/api` paths; leave `/health`/`/ready` shape unchanged.
5. Tests: missing `model` → 400 (OpenAI shape) on `/v1/audio/speech`; models list has the 3 ids
   with `object:"model"`; a voice with display `"アシュリー"` + key `ashley-ja` synthesizes and
   returns `X-Voice: ashley-ja` (no 500); 404 `/api/nope` and `GET /v1/audio/speech` 405 use the
   error shape; streaming still works.
6. Keep `/v1/audio/voices` emitting the key (already done). Do not edit takes/clone/voices routers.
