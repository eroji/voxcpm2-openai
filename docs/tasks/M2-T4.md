## Context

Implement the voice library routes. `VoiceStore` already provides `list/get/get` summaries,
`read_audio`, `update` (backs up + renames), `delete` (backs up). `importer.import_qwen3_speakers`
exists. Read `docs/CONTRACTS.md` §2, §4.

## Steps

1. `GET /api/voices` → `{"voices":[voice.summary(), ...]}`.
2. `GET /api/voices/{name}/audio` → `Response(audio.wav_bytes(*store.read_audio(name)),
   media_type="audio/wav")`. Unknown → 404 (store raises).
3. `PATCH /api/voices/{name}` body `VoicePatch`: pass only non-`None` fields to
   `store.update(name, new_name=..., ref_text=..., language=...)`; return `VoiceSummary`.
   Empty patch → 400. Rename to an existing name → 409.
4. `DELETE /api/voices/{name}` → `{"deleted": name}`.
5. `POST /api/voices/import?overwrite=false` → run `import_qwen3_speakers(store,
   settings.import_dir, overwrite=overwrite)` via `asyncio.to_thread` (disk I/O) and return its
   dict. Missing source dir is not an error.
6. Tests: list includes `ref_text` and `ref_duration_s`; audio returns RIFF; patch transcript and
   language; rename updates `voices.json` ordering; delete writes a backup zip; import route imports
   fixtures placed in `settings.import_dir` (write two safetensors there), second call skips,
   `?overwrite=true` replaces; unknown voice 404 on all name routes.
7. Do not edit `app/store.py`, `app/importer.py` or fixtures.
