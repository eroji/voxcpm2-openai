- **requirements:** R-025, R-026, R-043, R-020

## Context

Wave-2 review found:
- A 200-from-STT with a non-JSON (or non-object) body raises `ValueError` → plain-text 500; all
  errors must use the OpenAI shape.
- Upload decode/normalize/store run synchronously on the event loop; a compressed 19 MB upload can
  expand to gigabytes, and `ffmpeg` subprocesses in `app/audio.py` have **no timeout**, so one bad
  upload can stall every request and `/health`.
- The "max 20 MB" message is hard-coded; the clone stores `mime_type="audio/wav"` for MP3/FLAC
  uploads.
- `tests/test_studio_clone.py` asserts the monkeypatched setting instead of route behaviour; STT
  error paths are untested.

## Steps

1. `app/audio.py`: add a bounded `timeout` to `_run_ffmpeg` (default 60 s; `subprocess.run(...,
   timeout=timeout)`), catching `TimeoutExpired` → `RuntimeError("ffmpeg timed out")`. `resample`/
   `transcode` keep their signatures; add a unit test that a `timeout=0.001` run raises
   `RuntimeError` (use a real ffmpeg call on a long input, skip if ffmpeg is missing).
2. `studio_clone.py`:
   - STT: `try: payload = response.json(); text = payload["text"]` → on failure raise
     `APIError(502, "Transcription upstream returned an invalid response",
     type="upstream_error", code="stt_error")`. Handle non-2xx with the same 502 shape.
   - Upload: read bytes with the settings limit; use `sf.info(io.BytesIO(data))` (via a small
     helper in `audio.py` or inline) to check duration/frames **before** full decode, then run
     decode → trim → normalize → resample → `store.create` via `await asyncio.to_thread(...)` so the
     event loop stays free.
   - Error message interpolates `settings.max_upload_bytes` (MB).
   - Store `mime_type=file.content_type or "audio/wav"`.
3. Tests:
   - Fake STT returning 200 `text/plain` → 502 OpenAI shape; returning 500 → 502; returning
     `{"nope": 1}` → 502. Success path still `{"text": "hello"}`.
   - Clone with `settings.max_upload_bytes=1000` → 400 whose message contains "1000" (or the MB
     equivalent) and `code`; remove the assertion on the monkeypatched value.
   - Upload a 6 s MP3 (encode with ffmpeg from tone) → stored and `mime_type` reflects the upload,
     not always `audio/wav`.
   - Existing clone tests stay green; add one non-ASCII `ref_text` round-trip.
4. Do not edit `app/store.py`, `app/engine.py`, `app/speech.py` or fixtures.
