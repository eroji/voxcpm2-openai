GPU index (speech card is host index 1, in-container 0), the compose data volume path, spike
commands that duplicate/diverge from the tested scripts, missing reference audio in spike defaults,
and a smoke loop that masks failures.

     resolves to `/opt/voxcpm2-openai/deploy/data`; fix every backup/restore path and state it.
   - §7 spike commands: replace duplicated curls with the tested
     `python scripts/spikes/sN_*.py --base … --audio …` invocations; single source of truth.
   - Eight-voice acceptance loop must propagate failure (`rc=0; … || { rc=1; break; }; exit $rc`).
   - `mkdir -p /backup` before tar.

   every curl; keep key out of output. Re-run the happy/dead-server checks you used in M5-T1.

   - `--audio` defaults to `app/assets/warmup.wav` (or a required flag with a clear error), and every
     request carries `ref_audio` + `ref_text`; document that a real cloned voice is preferable.

   - S6: use `podman exec` (host uses Podman), keep docker as a fallback note.
4. `NOTES.md`: clarify S1/S4 fallbacks — the Style field / CFG / steps stay **until the spike runs**;
   if unsupported, hide/remove them per SPEC §12 (do not imply the opposite).
