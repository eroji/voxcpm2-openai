## Context

Implement the design flow behind one module so spike S2 can later swap the transport without
touching routes. VoxCPM2 design = synthesis with **no reference audio**, description carried as
`instructions`, and a per-candidate `seed`. Read `docs/CONTRACTS.md` §2, §4, §5. Candidates are
takes with `kind="design"` and `extra={"design_prompt", "design_seed"}` (Q-007).

## Steps

1. `app/design.py` — `DesignService(store, takes, engine, settings)`:
   - `async def candidates(req: DesignRequest) -> list[CandidateInfo]`: for `i in range(req.n)`
     pick `seed = secrets.randbelow(2**31 - 1) + 1`; call
     `engine.synth(SynthParams(text=req.sample_text, ref_audio=None, ref_text=None,
     instructions=req.description, seed=seed, fmt="wav"))`. If the engine raises `EngineError`
     (4xx upstream, e.g. `instructions` unsupported — S1/Q-018), retry once with
     `instructions=None`; record the prompt anyway. Decode WAV, `takes.create(..., voice="design",
     text=req.sample_text, language=req.language, kind="design", extra={...})`, build
     `CandidateInfo(id, index=i+1, seed, duration_s, audio_url, wave_url)`.
   - `async def save(candidate_id, name, language) -> Voice`: load the take (kind must be
     `design`), read its WAV, `store.create(name, samples, rate, ref_text=take["text"],
     language=language, consent="own-generated-voice", source="designed",
     metadata={"design_prompt": take.get("design_prompt",""), "design_seed":
     str(take.get("design_seed",""))})`.
2. `app/routers/studio_design.py`: `POST /api/design/candidates` → `{"candidates":[...]}`;
   `POST /api/design/save` → `VoiceSummary`. Unknown/non-design candidate → 404; duplicate name →
   409 (propagate).
3. Tests (`client`, `library`, `fake_engine`):
   - 3 candidates → 3 distinct seeds, each audio_url/wave_url, durations ~0.6 s, takes are
     `kind="design"` with `design_prompt`/`design_seed`.
   - `n=1` and `n=4` accepted; `n=0`/`n=5` → 400.
   - save → voice `source="designed"`, `consent="own-generated-voice"`, metadata has prompt+seed,
     `ref_text` equals `sample_text`; the new voice then synthesizes by name over `/v1` (same
     client) — assert 200.
   - unknown candidate → 404; saving a non-design take id → 404.
4. Do not edit `app/engine.py`, `app/store.py` or fixtures.
