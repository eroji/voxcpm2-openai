## Steps

1. `deploy/s6/engine/`: s6-overlay v3 longrun — `type` (`longrun`), `run` executable:
   `exec vllm serve "$MODEL_PATH" --omni --deploy-config "$DEPLOY_CONFIG"
   --served-model-name openbmb/VoxCPM2 --host 127.0.0.1 --port "$ENGINE_PORT"`, `down` file (or
   equivalent) if useful. No secrets, no shell interpolation tricks.
2. `deploy/s6/app/`: `type` longrun, `run`:
   `exec uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1` from `/opt/app`.
3. `deploy/s6/user/contents.d/engine` and `.../app` so s6-rc includes both services; engine starts
   before app (app `run` may wait for `/health`, or use s6 `dependencies.d/engine`).
4. Finish `deploy/Containerfile`: keep the existing base/uv/voxcpm install; `COPY app/ /opt/app/app`
   (keep the existing `COPY app/ /opt/app/` semantics if it already works), copy
   `deploy/voxcpm2-3090.yaml` → `/opt/app/deploy/`, copy `deploy/s6/` →
   `/etc/s6-overlay/s6-rc.d/` (v3 layout), install runtime Python deps with `uv pip install
   --system --break-system-packages --no-cache fastapi uvicorn[standard] httpx numpy soundfile
   safetensors pydantic pydantic-settings python-multipart` (matching `pyproject.toml`), and make
   the s6 `run` scripts executable. Keep `HF_HOME` on a writable path.
5. `tests/test_deploy.py`: assert the engine run script contains `vllm serve`, `--omni`,
   `--deploy-config`, loopback host and `$ENGINE_PORT`; app run contains `uvicorn app.main:app` and
   `0.0.0.0`; s6 user bundle lists both; Containerfile copies `deploy/s6`, the deploy config and
   `app/`; no `pip install voxcpm` (must stay uv); reference YAML unchanged (hash it in the test?
   no — just assert the path exists).

### Deviations

- Chose `dependencies.d/engine` over an in-`run` `/health` wait loop (brief allows either). s6
  dependency ordering only affects boot/bundle transitions; `s6-svc -r engine` (used by
  `/api/engine/restart`, CONTRACTS §5) restarts the engine without taking the app down.
- Added `rm -rf` of the base image's `engine`/`app` s6-rc dirs before the COPY so no stale files
  (e.g. an old `finish`) survive the overlay.
