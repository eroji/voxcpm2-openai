## Context

`index.html` has the Clone screen with `#drop-zone`, `#ref-file`, `#ref-text`, `#auto-transcribe`,
`#clone-name`, `#clone-lang`, `#consent`, `#test-line`, `#save-voice`, `#clone-error`; `core.js`
exports `api`, `state`, `loadVoices`, `play`, `showError`, `clearError`, `registerScreen`.

## Steps

1. `registerScreen("clone", { init, show })`: `init` binds everything; `show` refreshes
   `loadVoices()` (for name validation) and toggles `#auto-transcribe.disabled` when
   `/api/engine` or config says transcription is unavailable. Determine availability by calling
   `POST /api/transcribe` only on click and surfacing 503 as inline text; additionally try
   `api.get("/api/engine")` on show and leave the button enabled (the server is authoritative).
2. Drop zone: click opens `#ref-file`; `dragover` adds `is-over`, `dragleave`/`drop` remove it;
   dropping sets the file input's `files` (DataTransfer) and calls `onFile`.
3. `onFile`: read duration with `new Audio(URL.createObjectURL(file))` metadata; require 3–30 s
   (inline error naming the actual duration); otherwise show filename + duration text. Store the
   `File` in module state for save/test.
4. Auto-transcribe: `FormData` with `file` → POST `/api/transcribe`; fill `#ref-text`; on error
   `showError("clone", message)` (e.g. not configured).
5. Name: live validate against `/^[a-z0-9][a-z0-9_-]{0,63}$/` (lowercase input) and against
   `state.voices` names; show reason inline; `#save-voice.disabled` until file + valid name +
   consent checked.
6. Save: `FormData` with `file`, `name`, `language`, `ref_text`, `consent:"true"` → POST
   `/api/voices/clone`; on success clear form, reload voices, show success text ("Voice saved.") and
   route to `#voices` after a short delay (or leave; no auto-navigation required).
7. Test a line: require a file; `FileReader.readAsDataURL(file)` → POST `/v1/audio/speech` with
   `{model:"voxcpm2", voice: name || "ad-hoc", input: SAMPLE[language], response_format:"wav",
   ref_audio: dataUri, ref_text: #ref-text.value, stream:false}`; play the returned blob. Sample
   lines per language: en "This is a test of the cloned voice.", ja "これはクローンした声のテストです。",
   ko "이것은 복제한 음성의 테스트입니다.", zh "这是克隆声音的测试。".
8. Consent checkbox text is static in HTML; `#save-voice` gating uses its `.checked`.
