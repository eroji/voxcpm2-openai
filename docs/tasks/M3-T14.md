## Context

The updated `ui/studio.html`, `ui/starting.html`, `ui/presets.json` and `ui/icons/` add:
- Test-phrase presets for Speak (selected voice language, default Question, switching voice keeps the
  preset and swaps language) and Design (Design language).
- Empty-library states: Speak notice replaces chips + Generate disabled + “No takes yet”; Voices
  hides header actions/toolbar/table and shows one empty state (never both sets of buttons).
- Icons (favicon.svg/ico, PNGs, apple-touch) in the Studio and startup page.
- Startup log: row-per-line grid (time/source/level/message), ERROR/WARN styling, click to expand,
  no horizontal scroll.
Our existing startup page has M3-T13 fixes (clipboard fallback, focus, visible errors) that must be
preserved when merging the new reference.

## Steps

1. Copy `ui/presets.json` → `app/static/presets.json`; copy `ui/icons/*` (not `concepts/`) →
   `app/static/icons/`; add favicon `<link>`s to `index.html` and `starting.html`
   (`/static/icons/...`).
2. `index.html`:
   - Speak: add `#speak-novoice` block, `#gen-hint`, `#takes-empty`, `lang` on the textarea, preset
     row `#speak-presets` + `#speak-lang-name`.
   - Voices: wrap actions in `#voices-actions`, add `#voices-empty`, wrap toolbar/table in
     `#voices-list`; header buttons only inside those containers.
   - Design: `#design-lang` options get values `ja|en|ko|zh`; add `#design-presets` under the sample.
   - Keep the existing real element IDs required by the modules.
3. `speak.js`:
   - Fetch `/static/presets.json` once; render six chips into `#speak-presets`; default `question`.
   - Selected voice language comes from `state.voices.find(v => v.key === state.selectedVoice)?.language`
     (fallback en); update `#speak-lang-name`; when the voice changes, keep the selected preset id
     and replace the text with that language's version; chip click sets `aria-pressed` and text/lang.
   - Empty state: when `state.voices` is empty, hide chips, show `#speak-novoice`, show `#gen-hint`,
     set `aria-disabled="true"` on Generate (clicking focuses the notice’s first button) and show
     `#takes-empty`; otherwise reverse. Do not call the API when empty.
4. `voices.js`: when the library is empty, hide `#voices-actions`, `#voices-list` and the count,
   show `#voices-empty`; when non-empty, the opposite. Remove the old inline empty row.
5. `design.js`: fetch the same presets; render chips for `#design-lang` value (`ja/en/ko/zh`); update
   the textarea `lang` and swap text when a preset is selected; changing language re-renders chips
   and swaps text if a preset is active. No preset selected initially (reference text stays).
6. `starting.html`: merge the new log table layout/parser and 30/70 column grid from `ui/starting.html`
   into `app/static/starting.html`, keeping M3-T13’s clipboard fallback, log `tabindex`/region,
   `#startup-error` and restart-error handling. Clicking a row toggles `.open`.
7. Tests:
   - `test_ui_assets.py`: presets file served/valid (6 per language, required ids), both pages link
     the icons, empty-state IDs exist, design values are `ja|en|ko|zh`, startup log rows use the
     grid parser.
   - `tests/e2e`: add an empty-library app (no voices seeded): Speak shows the notice, Generate is
     aria-disabled and focuses the first button, takes-empty visible; Voices shows only the empty
     state (no header buttons/table). On the seeded app: select a Japanese voice → preset text is
     Japanese and label shows Japanese; switch preset then voice → same preset id in the new
     language. Design language change swaps preset text. Startup log row click expands.
8. Do not edit Python code or other modules.

### Deviations

- The empty-library Generate click in e2e uses `dispatch_event("click")`: Playwright refuses to
  actionability-click a button with `aria-disabled="true"`, while real browsers fire the handler.
- `#speak-presets` chips stay visible with an empty library (SPEC §8: "Text, presets and parameters
  stay editable"), rendered in the `en` fallback language.
- `tests/e2e/conftest.py` (lead-owned) has no empty app, so `live_app_empty` is a session fixture
  in `test_studio.py` built from conftest's own `_serve`/`_settings` — no conftest edit.
