## Context

Read `docs/CONTRACTS.md` §2–§3. The router must declare `dependencies=[Depends(require_v1)]` so

## Steps

1. `POST /v1/audio/speech`:
   - Parse `SpeechRequest` (model caps at 4000); also reject
     `len(input) > settings.max_input_chars` with `BadRequest` (configured limit).
   - `seq = await request.app.state.speech.synthesize(payload)` (non-stream) →
     `Response(seq.audio, media_type=seq.media_type, headers={...})` with `X-Voice`,
     `X-Sample-Rate`, `X-Audio-Duration` (`f"{duration:.3f}"`), `X-RTF` (`f"{rtf:.4f}"` when known).
   - `stream=true` → `streaming = await speech.stream(payload)` (raises 429/503 here, before
     headers); wrap `streaming.chunks` in an async generator with
     `try/finally: await streaming.aclose()` and also pass
     `background=BackgroundTask(streaming.aclose)` so a client that disconnects before the first
     chunk cannot leak the engine slot. Headers `X-Voice`/`X-Sample-Rate` only; no
     `Content-Length`.
   - Accept `task_type`/unknown fields (pydantic already ignores); all 5 formats; `sample_rate`;
     `speed`; ad-hoc `ref_audio` (handled by `SpeechService.resolve`).
2. `GET /v1/models` → the single card from §2. `GET /v1/audio/voices` → names/language/source from
   `request.app.state.store.list()`.
3. Tests:
   - 200 WAV for `{"model":"tts-1","voice":"ashley-en","input":"hello"}`: `RIFF` magic, 48 kHz
     header, `X-Voice`, `X-RTF`, `X-Audio-Duration`.
   - case-insensitive voice (`ASHLEY-EN`); unknown voice → 400 whose message lists `ashley-en`.
   - `input` of 4001 chars → 400 OpenAI shape; `response_format` invalid → 400 shape.
   - formats: wav/pcm/mp3/opus/flac content types; pcm length is 2 bytes/sample; `sample_rate=24000`
     header reflects 24000; `speed=2.0` duration roughly halves.
   - streaming: `client.stream(... stream=True, response_format="pcm")` yields ≥ 2 chunks; wav stream
     starts with `RIFF` and has `X-Sample-Rate`; mp3 stream non-empty.
   - API key: build a second app with `Settings(api_keys="k1", ...)`; 401 without bearer, 200 with.
   - `GET /v1/models` + voices shape.
4. Do not edit `app/speech.py`, `app/audio.py`, `app/engine.py` or fixtures. Report BLOCKED if a
   contract is insufficient.
