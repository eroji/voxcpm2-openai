## Context

`ui/studio.html` changed the Engine stat grid: fixed 4 columns (2 at ≤900 px, 1 at ≤520 px),
ellipsised `.v` values with full names in `title`, updated labels/notes, and pretty-printed endpoint
JSON. `ui/starting.html` is a new standalone startup page which the app will serve at `/` until
warm (backend task M2-T15b). Port both; the backend will load `app/static/starting.html`.

## Steps

1. Copy `ui/starting.html` → `app/static/starting.html`, changing only the stylesheet href to
   `/static/tokens.css`. Keep the demo mode (`?demo=failed`) for file preview, but the live path
   polls `/ready` + `/api/engine/startup` every 2 s and calls `location.replace('/')` once ready.
2. `studio.css`: `.vs-stats` → `repeat(4, minmax(0,1fr))` with 900/520 px breakpoints; `.vs-stat .v`
   gets `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`.
3. `engine.js` stat blocks to match the new reference:
   - Model: value = last path segment (`VoxCPM2`), `title` = full `openbmb/VoxCPM2`, note
     `openbmb/VoxCPM2 · 2B · 48 kHz`.
   - GPU: value = GPU name without the `NVIDIA GeForce ` prefix, `title` = full name, note
     "Shared with whisper-stt, TEI" (keep the reference copy).
   - "GPU memory used": `9.3 GB`, note `of 24 GB, all processes on the card`.
   - KV cache unchanged; Warm RTF note "Last 20 requests, warm-up excluded"; First audio unchanged;
     Voices unchanged; Runtime: value `vLLM-Omni`, note the version(s) from `e.runtime`
     (e.g. `0.30.0 · vLLM 0.30.0`).
4. Endpoint example: use `JSON.stringify(body, null, 2)` (already) so it matches the reference's
   multi-line body.
5. `tests/test_ui_assets.py`: assert `app/static/starting.html` exists, links `/static/tokens.css`,
   polls `/api/engine/startup`, uses `location.replace('/')`, has the failed state (`?demo=failed`
   or `body.failed`), and that the Engine CSS has the 4/2/1 columns + ellipsis + new labels.
6. `tests/e2e/test_studio.py`: update Engine-screen assertions for the new labels/notes; keep the
   existing 1280/390 screenshots (the startup page gets its e2e in M2-T15b).
