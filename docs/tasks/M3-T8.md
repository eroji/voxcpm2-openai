## Context

Wave-4 review found the clone screen reads `state.engine` before it is loaded (cold deep link), and
`show()` can throw before the gating runs if `/api/voices` fails; the result is auto-transcribe
enabled without STT or Test-a-line enabled while `/v1` needs a bearer key. Also `#clone-status` has
no `.vs-status` CSS rule, and a `title` on a disabled button is not announced.

## Steps

1. `index.html`: mark `#auto-transcribe` and `#test-line` `disabled` in the markup (safe default),
   and add a visible hint element (e.g. `<p class="meta" id="clone-notes">`) used for the
   "Test a line needs /v1 access" explanation via `aria-describedby` when disabled.
2. `clone.js` `show()`: `await Promise.allSettled([refreshEngine(), loadVoices()])` (import
   `refreshEngine` from core), then set gating from `state.engine` — auto-transcribe enabled only
   when `stt` is true; test-line enabled only when `api_keys_required` is false. Run the gating in a
   `finally` so a voices failure cannot skip it. Call `updateSave()` on the cancel/undefined-file
   path too. Add a probe sequence token so an older duration probe cannot overwrite a newer file.
   Wrap the post-save `loadVoices()` so a refresh failure does not report the save as failed.
3. `studio.css`: add `.vs-status { margin: var(--vs-s4) 0 0; font-size: var(--vs-fs-small);
   color: var(--vs-muted); }` (tokens only, no new colors).
4. `tests/test_ui_assets.py`: assert both buttons are disabled in HTML, `.vs-status` exists, clone
   imports `refreshEngine`, and `show()` gates inside `finally`; ensure the import/export check
   still passes.
5. Do not edit other screen modules or Python code.

## Report

  `finally`, so a `/api/voices` failure cannot skip gating. Added `probeSeq` token so an older
  duration probe cannot overwrite a newer pick. `updateSave()` (plus reset of the drop-zone meta
  text) now runs on the cancel/undefined-file path. Post-save `loadVoices()` wrapped in
  `try/catch` — a refresh failure no longer reports the save itself as failed.
- `app/static/studio.css` — added `.vs-status { margin: var(--vs-s4) 0 0; font-size:
  var(--vs-fs-small); color: var(--vs-muted); }` (tokens only).
