# M2-T12 — Store list without audio decode, unique backups, take invariants

- **Milestone:** M2
- **Wave:** 8
- **owns:** `app/store.py`, `app/routers/studio_takes.py`, `tests/test_store.py`, `tests/test_studio_takes.py`
- **deps:** M2-T9, M2-T11
- **verify:** `.venv/bin/python -m pytest tests/test_store.py tests/test_studio_takes.py -q && .venv/bin/ruff check app/store.py app/routers/studio_takes.py tests/test_store.py tests/test_studio_takes.py`
- **requirements:** R-009, R-010, R-024, R-027, R-028

## Context

Release review found:
- `VoiceStore.list()` loads every voice's full audio tensor; `/api/engine` polls it every 5 s and
  `/v1/audio/voices` on demand. With a large library this blocks/starves the 2-slot queue.
- Backups are named to the second, so two same-second edits with the same reason overwrite the
  earlier snapshot (SPEC §5 promises a pre-change backup).
- `prune()` ignores orphan WAVs/corrupt JSON → `takes/` grows.
- `/api/takes` returns design candidates in the Speak Takes list; `/api/speak` stores at
  `settings.sample_rate` (not always 48 kHz — SPEC §5); saving a design take as a voice marks it
  `source="uploaded"`.
- `X-Voice` on the streaming path should use the ASCII key / `safe_header_value` (M1-T14).

## Steps

1. `app/store.py`:
   - Add `_read_voice_meta(path) -> Voice`-like lightweight read: `safe_open` metadata plus the
     cached duration from `voices.json` (compute once from the tensor only if the cache is
     missing, then persist). `list()` uses it; `get()`/`read_audio()`/`data_uri()` keep loading the
     tensor.
   - `backup(reason)`: append `secrets.token_hex(2)` to the filename (still time-sortable).
   - `prune()`: also remove `*.wav` without a matching JSON and malformed `*.json` older than the
     retention window; never raise.
2. `app/routers/studio_takes.py`:
   - `GET /api/takes?kind=studio` default `studio`, `all` opt-in; Use `TakeInfo` rows filtered by
     `kind`.
   - Non-stream saved take always 48 000 Hz: `model_copy(update={..., "sample_rate": 48000,
     "speed": 1.0, "response_format": "wav"})`; streamed take resample to 48 000 before saving.
   - `save-as-voice`: if the take `kind == "design"`, use `source="designed"`, consent
     `own-generated-voice`, and carry `design_prompt`/`design_seed` metadata; otherwise keep the
     current behaviour.
   - `X-Voice`: use `models.safe_header_value` (import from `app.models`).
3. Tests:
   - `list()` must not call `get_tensor` (monkeypatch `safetensors.safe_open` to fail on
     `get_tensor` for list, or assert with a spy); durations still correct from the index.
   - Two same-second backups with the same reason produce two files, both readable.
   - Prune removes orphan WAV and corrupt JSON without raising.
   - Takes list hides `kind="design"` by default and shows it with `?kind=all`.
   - Take is 48 kHz with `SAMPLE_RATE=24000` and `sample_rate=24000` requested.
   - Saving a design take produces `source="designed"` and the design metadata.
4. Do not edit speech/models/engine or fixtures.
