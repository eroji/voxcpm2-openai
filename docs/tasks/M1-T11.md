## Context

Wave-5 review proved:

- `s6-svc -r` returns immediately, so `/api/engine/restart` warms the **old** process or fails;
  `WarmupService.run_forever` exits after its first success, so `/ready` stays 503 forever after a
  crash. SPEC §4/§7 require restart→warm-up and honest readiness.
- `/ready` trusts `warmup.warm` only; a dead engine still reports ready.
- No HTTP-level test proves `QueueFull` becomes `429` + `Retry-After` on `/v1/audio/speech` and
  `/api/speak` (only the engine client is tested).

## Steps

1. `EngineClient.restart()`: set `_ready = False`, run `s6-svc -r`, `await asyncio.sleep(0.5)`,
   then `await self.wait_ready(120)`. If not healthy → `EngineError("engine did not become healthy
   after restart")`. (Update CONTRACTS §5 timing note.)
2. `WarmupService`:
   - `run()` starts with `if not await self.engine.wait_ready(self.settings.warmup_timeout_s):
     self.warm = False; self.last_error = "engine is not ready"; return False`.
   - `run_forever()` never exits: loop — if `not engine.ready`: `warm = False`,
     `last_error = "engine is not ready"`, `await asyncio.sleep(2)`, continue; if `warm`: sleep 2,
     continue; else `await run()`; sleep 2 on failure, 10 on success. Cancellation exits cleanly.
3. `/ready` (`app/routers/system.py`): 200 only when `warmup.warm and engine.ready`; otherwise 503
   with `Retry-After: 5` and `reason = warmup.last_error or "engine is not ready"`.
4. Tests:
   - Stub engine whose `restart` makes health false for ~0.3 s then true; `/api/engine/restart`
     (with real `WarmupService` and `wait_ready` stubbed to wait then succeed) returns
     `{"restarted": true, "warm": true}`; `/ready` becomes 200 afterwards.
   - `run_forever`: health false → `warm` cleared; when health recovers (stub), it re-warms without
     a manual call (drive with `asyncio.wait_for` and a short timeout; no unbounded sleeps).
   - `/ready` 503 when `warm` is true but `engine.ready` is false.
   - `tests/test_queue_http.py`: monkeypatch `app.state.speech.synthesize` to raise `QueueFull`
     → `/v1/audio/speech` 429 with `Retry-After: 1` and OpenAI body; same for `/api/speak`
     non-stream. Monkeypatch `speech.stream` to raise `QueueFull` → streaming `/v1` 429 (no 200).
5. Do not edit routers other than `system.py`, speech, store or fixtures.
