# M2-T7 — Store/importer key, backup safety, prune guard (wave-2 review)

- **Milestone:** M2
- **Wave:** 3
- **owns:** `app/store.py`, `app/importer.py`, `tests/test_store.py`, `tests/test_importer.py`
- **deps:** M2-T6
- **verify:** `.venv/bin/python -m pytest tests/test_store.py tests/test_importer.py -q && .venv/bin/ruff check app/store.py app/importer.py tests/test_store.py tests/test_importer.py`
- **requirements:** R-010, R-011, R-025

## Context

Wave-2 review found:
- Import derives the file key from the display `name`; SPEC §5 keys are `voice_name_lower`. A file
  with `name="Ashley EN"` + `voice_name_lower="ashley-en"` is rejected or stored under a different
  key, and language inference uses the wrong string.
- `_read_voice_file` trusts metadata `voice_name_lower` over the filename; a hand-placed file with
  `../../escape` makes delete/update raise and `backup()` interpolates it into a path outside
  `backups/`.
- `TakeStore.prune()` raises if a JSON's WAV is missing, turning the next `create()` into a 500.
- `meta.setdefault("file_size", str(len(wav_bytes(...))))` re-encodes every voice even when the
  value is already present.
- No non-ASCII round-trip test.

## Steps

1. `VoiceStore.create(..., key: str | None = None)`:
   - `key = validate_voice_name(key or name)`; write `<key>.safetensors`; metadata
     `voice_name_lower=key`, `name=display name`.
   - Compute `file_size` only when absent (`if "file_size" not in meta: ...`).
2. `_read_voice_file`: derive `key` from `path.stem` (validated) and ignore a conflicting metadata
   value (metadata `voice_name_lower` is rewritten on the next write). Never use metadata for path
   construction.
3. `backup(reason)`: sanitize `reason` with `re.sub(r"[^A-Za-z0-9_-]", "_", reason)[:60]` before
   building the filename; keep the zip layout unchanged.
4. `TakeStore.prune()`: delete missing files with `unlink(missing_ok=True)` on the paths directly
   (no `audio_path` call that raises); skip malformed ids.
5. `importer.py`: `key = meta["voice_name_lower"] or path.stem`; display `name = meta["name"] or
   key`; language inferred from **key**; call `store.create(name, ..., key=key)`.
6. `_uri_cache` bounded: evict oldest when > 64 entries (simple insertion-order pop).
7. Tests:
   - Import file `name="Ashley EN"`, `voice_name_lower="ashley-en"` → `ashley-en.safetensors`,
     display name preserved, language from key.
   - Hand-placed file with metadata key `../../escape` → `get`/`delete` work on the filename key;
     `backup` stays inside `backups/`; no exception.
   - Take JSON with missing WAV → `create()` still succeeds (prune does not raise).
   - Caller-provided `file_size` is preserved and `wav_bytes` is not called (monkeypatch it to
     raise, assert import still succeeds).
   - Japanese/Korean/Chinese `ref_text` round-trips through create/get/list and `voices.json`.
   - Existing tests stay green.
