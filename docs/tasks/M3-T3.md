## Context

`index.html` has the Voices screen with `#voice-search`, `#lang-filters`, `#voice-rows`,
`#voices-count`, `#voices-error`; `core.js` provides `api`, `state`, `loadVoices`, `play`,
`showError`, `clearError`, `formatLang`, `fmtDuration`, `registerScreen`. Implement the module only.

## Steps

1. `registerScreen("voices", { init, show })`: `show` calls `loadVoices()` then `render()`.
   `init` binds search input (`input` event), language filter clicks (`aria-pressed` single-select;
   values `all|en|ja|ko|zh`), and a delegated click handler on `#voice-rows`.
2. `render()`: filter `state.voices` by case-insensitive match on name+ref_text and language;
   set `#voices-count` to the visible count; build rows:
   - name (bold), language (`formatLang`), source with `<span class="src [designed]">Uploaded|Designed</span>`,
     reference `fmtDuration(ref_duration_s)`, transcript cell (one line, CSS ellipsis),
     actions Audition / Edit / Delete.
   - Empty state row/area: "No voices yet. Clone one from a recording or design one from a
     description." with buttons routing to `#clone` / `#design`.
3. Audition → `play(`/api/voices/${encodeURIComponent(name)}/audio`)`.
4. Edit (inline row editor): replace the row with inputs for name, a select for language
   (en/ja/ko/zh), a text input for transcript, Save/Cancel. Save → PATCH
   `/api/voices/{name}` with changed fields only → reload; 409 error shown inline. Cancel restores.
5. Delete: replace the actions cell with the text "Delete <name>? This can't be undone from the
   UI." + Delete/Cancel. Delete → DELETE → reload. Errors inline via `showError("voices", ...)`.
6. Use `textContent` for all API data; `encodeURIComponent` in URLs.

Implementation notes:

- `registerScreen("voices", { init, show })`; `show` = `await loadVoices()` then `render()`.
- Search (`input` event, lowercased) and language filter (`aria-pressed` single-select on
  `#lang-filters`, values `all|en|ja|ko|zh`) compose in `visibleVoices()`: match on
  `name + ref_text` case-insensitively plus lowercased `language`.
- Rows built with `createElement`/`textContent` only: name (`td.name`), `formatLang(language)`,
  `<span class="src [designed]">Uploaded|Designed</span>`, `fmtDuration(ref_duration_s)`,
  `td.tx` transcript (CSS ellipsis), actions Audition/Edit/Delete (`td.act`, `btn-link`).
- Empty state (only when `state.voices` is empty, i.e. filters aren't hiding rows): row with
  `div.vs-empty` and the exact copy from the brief plus two buttons routing to `#clone`/`#design`
  via `location.hash` (dynamic buttons can't rely on core's one-time `[data-goto]` binding).
- One delegated click handler on `#voice-rows` dispatches on `button[data-act]` within
  `tr[data-name]`: audition → `play(`/api/voices/${encodeURIComponent(name)}/audio`)`; edit →
  inline row editor (name text input, en/ja/ko/zh select, transcript text input, Save/Cancel);
  delete → actions cell replaced with `Delete <name>? This can't be undone from the UI.` +
  Delete/Cancel. No `confirm()` anywhere.
- Save PATCHes `/api/voices/{name}` with changed fields only (`new_name`, `language`, `ref_text`;
  language compared case-insensitively); on success `clearError` + reload + `render()`; on failure
  (e.g. 409) `showError("voices", …)` and the editor stays open. Cancel re-renders (restores).
  Delete follows the same pattern via `api.del`.
