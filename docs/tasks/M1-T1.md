## Context

Replace the `NotImplementedError` bodies in `app/engine.py` with the real client. Read
`docs/CONTRACTS.md` §5 — the class, dataclasses and signatures are frozen; `SynthParams`,
`SynthResult`, `EngineStats` already exist. `tests/conftest.py` provides a session-scoped
`fake_engine` (`.url`, `.state`, `.reset()`), which serves `/health`, WAV and streamed PCM.

Engine protocol (assumed, pending spike S1–S4; Q-002/Q-004): POST `{base}/v1/audio/speech` JSON
`{model, input, ref_audio, ref_text, response_format: "wav"|"pcm", stream, instructions?, speed?,
seed?, cfg?, steps?}`. 48 kHz mono output.

## Steps

1. Write `tests/test_engine.py` first:
   - `health()` true against `fake_engine.url`, false against a closed port.
   - `synth()` on a 1 s reference returns `SynthResult` whose bytes decode to ~0.6 s at 48 kHz and
     `rtf` is a float > 0.
   - `stream()` yields ≥ 2 chunks totalling 0.6 s of s16le at 48 kHz (decode with
     `app.audio.pcm_s16le_to_float`).
   - Queue: `EngineClient(concurrency=1, max_queue=0)`, start two `asyncio.gather`ed `synth` calls
     with input `"slow"` (fake engine sleeps 0.25 s); at least one raises `QueueFull`.
   - `stats()` never raises with nvidia-smi absent and reports `max_concurrency`/`queue_depth`.
   - `cfg`/`steps` rejection retry: point at a tiny ASGI app served by uvicorn in the test that
     returns 422 when `steps` is present; assert one retry without them and a warning logged once.
2. Implement:
   - `start()` creates `httpx.AsyncClient(base_url=..., timeout=...)` and starts a health poll loop
     (2 s interval) that updates `ready`; `aclose()` cancels it and closes the client.
   - `synth()`/`stream()` acquire a slot first (`QueueFull` when `waiting >= max_queue`), re-check
     readiness once (`await self.health()` if not ready) then raise `EngineNotReady` if still down.
     Map non-2xx engine responses to `EngineError` with the upstream message (400/422 stay 4xx?
     No: upstream failures are 502 — the *app* validates client input before this call).
   - `stream()` is an async generator: `client.stream("POST", ...)`, yield `aiter_raw()` chunks,
     record `first_audio_ms` on the first chunk.
   - Rolling deques of `metrics_window` for rtf and first-audio; `stats()` averages or `None`.
   - `restart()` runs `s6-svc -r {service_dir}/{s6_service}` via `asyncio.create_subprocess_exec`,
     timeout 30 s, `EngineError` on non-zero.
   - VRAM/GPU via `subprocess.run(["nvidia-smi", ...], timeout=2)` guarded by `except Exception`.
3. Keep `from_settings()` working. No new dependencies.
