# M1-T14 — `/v1/models` single entry, instructions fallback, upstream 429/503, header safety

- **Milestone:** M1
- **Wave:** 8
- **owns:** `app/models.py`, `app/engine.py`, `app/routers/v1.py`, `tests/test_v1.py`, `tests/test_engine.py`
- **deps:** M1-T12
- **verify:** `.venv/bin/python -m pytest tests/test_v1.py tests/test_engine.py -q && .venv/bin/ruff check app/models.py app/engine.py app/routers/v1.py tests/test_v1.py tests/test_engine.py`
- **requirements:** R-013, R-015, R-019, R-020, R-021

## Context

Release review found:
- `/v1/models` returns three cards; SPEC §6 says **one entry `voxcpm2`** with aliases accepted on
  request. Q-025 contradicted Q-011/CONTRACTS; SPEC wins.
- `instructions` has no fallback: if S1 shows it is unsupported, every styled request 502s instead
  of the spec's "accept, ignore, log once".
- Upstream engine 429/503 become 502 with no `Retry-After`.
- `X-Voice` accepts CR/LF/C0 and unbounded length for ad-hoc labels (header injection / 500).
- `stats()` sums deques from a worker thread while the loop appends (rare
  `deque mutated during iteration`).

## Steps

1. `app/routers/v1.py`: `/v1/models` returns exactly one card `voxcpm2`; aliases remain accepted
   as the request `model`. Update `tests/test_v1.py`.
2. `app/engine.py`:
   - Add `_supports_instructions`; in `_post`, on 400/415/422 whose message mentions
     `instructions`, drop it and retry once, logging once (mirror cfg/steps).
   - Map upstream `429` → `QueueFull`, `503` → `EngineNotReady` (before the generic EngineError);
     keep `Retry-After` semantics.
   - Guard `_record` and `stats()` with a `threading.Lock` so thread snapshots are consistent.
3. `app/models.py`: add `def safe_header_value(value: str) -> str` returning `"ad-hoc"` when the
   value is empty, >64 chars, or contains non-printable/non-ASCII characters.
4. `app/routers/v1.py`: use `safe_header_value(seq.key or seq.voice)` for `X-Voice`; the takes
   router will import the same helper in M2-T12.
5. Tests: models list has exactly one id; `model:"tts-1"` still synthesizes; an engine stub that
   rejects `instructions` once retries without it and logs once; a 429 stub → `QueueFull` with
   `Retry-After` on `/v1`; a 503 stub → `EngineNotReady`; `voice:"a\r\nX-Evil: 1"` with ad-hoc
   `ref_audio` returns `X-Voice: ad-hoc` (no injected header, no 500); 1000-char voice label →
   `ad-hoc`.
6. Update `docs/PLAN.md` Q-011/Q-025 contradiction is the lead's job — note it in the Report.

- [ ] `verify:` green; output in `## Report`.
