## Context

Release review found:
- `/v1/models` returns three cards; SPEC §6 says **one entry `voxcpm2`** with aliases accepted on
  request. Q-025 contradicted Q-011/CONTRACTS; SPEC wins.
- `instructions` has no fallback: if S1 shows it is unsupported, every styled request 502s instead
  of the spec's "accept, ignore, log once".
- Upstream engine 429/503 become 502 with no `Retry-After`.
- `X-Voice` accepts CR/LF/C0 and unbounded length for ad-hoc labels (header injection / 500).
- `stats()` sums deques from a worker thread while the loop appends (rare
  `deque mutated during iteration`).

   `ad-hoc`.

## Report

### Files changed

- `app/models.py` — added `safe_header_value(value) -> str`: returns `"ad-hoc"` when the value is
  empty, >64 chars, or contains non-ASCII/non-printable characters (covers CR/LF/C0 injection and
  unbounded labels).
- `app/engine.py` —
  - `_supports_instructions` flag; `_payload(..., instructions=)`; in `_post`, a 400/415/422 whose
    message mentions `instructions` drops it, retries once and logs once (mirrors the cfg/steps
    Q-004 path).
  - Upstream `429` → `QueueFull` (numeric `Retry-After` from the upstream header is passed through,
    default 1) and `503` → `EngineNotReady` (fixed `Retry-After: 5`), raised before the generic
    `EngineError`; both after `resp.aclose()` so no body leaks.
  - `threading.Lock` (`_stats_lock`) guards `_record` appends and the `stats()` deque snapshot so
    the `asyncio.to_thread` stats reader can't hit `deque mutated during iteration`.
- `app/routers/v1.py` — `/v1/models` returns exactly one card `voxcpm2` (SPEC §6; aliases remain
  accepted as the request `model` because `SpeechRequest.model` accepts any string); `_voice_header`
  now delegates to `safe_header_value(seq.key or seq.voice)`.
- `tests/test_engine.py` — `_rejection_app` parameterized (`field`, `status`); added
  `test_instructions_rejected` (one 400, one retry without `instructions`, exactly one warning,
  later calls omit it up front), `_status_app`, `test_upstream_429_maps_to_queue_full`
  (`Retry-After: 7` preserved), `test_upstream_503_maps_to_engine_not_ready`.
- `tests/test_v1.py` — `test_models_card` asserts exactly one id `voxcpm2`; added
  `test_upstream_429_becomes_429_with_retry_after`, `test_upstream_503_becomes_503_engine_not_ready`
  (real `EngineClient` against a stub server through `create_app(engine=...)`),
  `test_voice_header_injection_neutralized` (`voice:"a\r\nX-Evil: 1"` + ad-hoc `ref_audio` → 200,
  `X-Voice: ad-hoc`, no `X-Evil`), `test_long_voice_label_neutralized` (1000-char label → `ad-hoc`).
  `model:"tts-1"` synthesis is covered by the existing `test_speech_wav_ok` (BODY uses `tts-1`).
