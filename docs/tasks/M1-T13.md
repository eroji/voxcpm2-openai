# M1-T13 — CI correctness, local-gate parity, auth fail-fast, 500 shape

- **Milestone:** M1
- **Wave:** 8
- **owns:** `.gitlab-ci.yml`, `scripts/verify.sh`, `app/config.py`, `app/main.py`, `tests/test_config.py`, `tests/test_auth.py`
- **deps:** M1-T11, M1-T12, M2-T11
- **verify:** `.venv/bin/python -m pytest tests/test_config.py tests/test_auth.py -q && bash -n scripts/verify.sh && .venv/bin/ruff check app/config.py app/main.py tests/test_config.py tests/test_auth.py`
- **requirements:** R-020, R-041, R-049, R-050, R-051

## Context

Release review found:
1. `default.before_script` (apt-get + pip) is inherited by the `javascript` (node:22-alpine) and
   `deploy:*` (alpine) jobs → `apt-get: not found`, so the mandatory checks stage is red.
2. `scripts/verify.sh` omits the CI JS check, `python -m build`, and the package contract check,
   although the runbook claims parity.
3. `STUDIO_AUTH="admin"` (no colon) or `":pass"` silently disables Basic auth; `API_KEYS="   "`
   leaves `/v1` open (SPEC §10 fail-open).
4. Unhandled exceptions return Starlette's plain 500, not the OpenAI shape; `/docs` is open and
   loads CDN assets (R-003); the HTTPException handler drops `Allow` on 405; non-ASCII
   `STUDIO_AUTH` makes `compare_digest` raise.
5. CI `package` is green without building an image when Harbor creds are absent.

## Steps

1. `.gitlab-ci.yml`:
   - `javascript`, `deploy:staging`, `deploy:production`: add `before_script: []` (they install
     what they need in `script`).
   - Split packaging: `package:check` (always, static Containerfile contract) and `package`
     (rules `- if: $HARBOR_USER`, real docker build/push, `needs: [package:check]`). A missing
     credential is a skipped job, never a green package.
   - Keep `build`, `test`, `e2e`, `deploy:*` rules; production still tag + manual.
2. `scripts/verify.sh`: add the JS parse loop (fail if node missing), `python -m build` to a temp
   dir (`--outdir dist`), and the package contract check (s6 dirs + Containerfile greps) so local
   and CI run the same commands.
3. `app/config.py`: add `def validate(self) -> None` — if `studio_auth` is non-empty it must parse
   to a non-empty user and password, else `raise RuntimeError`; if `api_keys` is non-empty there
   must be at least one non-blank token. Call it at the start of the lifespan and in `create_app`
   (so tests can assert). Keep `studio_credentials` returning the tuple.
4. `app/main.py`: add an `Exception` handler returning 500
   `{"error":{"message":"Internal server error","type":"internal_error","code":"internal_error"}}`
   and log the traceback; preserve `headers=exc.headers` in the `StarletteHTTPException` handler;
   use byte comparison for Basic auth (non-ASCII must be 401/startup error, never 500); set
   `docs_url=None, redoc_url=None, openapi_url=None`.
5. Tests: malformed `STUDIO_AUTH`/blank `API_KEYS` → startup `RuntimeError`; valid values still
   work; non-ASCII Basic header → 401 not 500; a route that raises → OpenAI 500 shape; 405 on
   `/v1/audio/speech` keeps `Allow`.
6. Do not edit routers or other app modules.

## Definition of done

- [ ] `verify:` green; output in `## Report`.
- [ ] `node --check`, build and package checks are in both CI and `scripts/verify.sh`.
- [ ] Auth configuration fails closed at startup; no plain 500 for API paths.
