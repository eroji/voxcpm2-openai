## Context

Implement the three engine routes using `request.app.state.{engine, warmup, store, settings}`.
`EngineClient.stats()` returns everything except voice count and warm state. Read
`docs/CONTRACTS.md` §2, §5.

## Steps

1. `GET /api/engine`: run `stats = await asyncio.to_thread(engine.stats)` — it shells out to
   `nvidia-smi` and must not block the event loop — then return
   `EngineStatus(ready=warmup.warm, reason=warmup.last_error, model=stats.model,
   runtime=stats.runtime, gpu=stats.gpu,
   vram_used_mb=..., vram_total_mb=..., kv_cache=stats.kv_cache, max_concurrency=...,
   rtf=stats.rtf, first_audio_ms=stats.first_audio_ms, voices=len(store.list()),
   queue_depth=stats.queue_depth, stt=bool(settings.stt_url),
   api_keys_required=bool(settings.api_key_set))`. `ready` must mean **warm**, not merely health.
2. `POST /api/engine/warmup` → `ok = await warmup.run()`; return `{"warm": ok}` with 200 when ok,
   503 `EngineNotReady` with the last error when not.
3. `POST /api/engine/restart` → set `warmup.warm = False`, `await engine.restart()`, then
   `await warmup.run()`; return `{"restarted": true, "warm": ok}` (503 if warm-up fails). On
   `restart` failure propagate `EngineError` (502).
4. Tests (`client`, `library`, `fake_engine`):
   - `/api/engine` returns model, runtime, `max_concurrency=2`, voices=2, queue_depth, `ready` true
     after warm-up (poll `/ready` first), `reason` (None when warm), `stt` false with no
     `STT_URL`, `api_keys_required` false without `API_KEYS`, GPU fields may be `None`. Add a
     second app with those envs set and assert both flags flip.
   - `/api/engine/warmup` triggers ≥ 2 fake-engine calls and returns `{"warm": true}`.
   - restart with `engine.restart` monkeypatched to an async no-op → `{"restarted": true,
     "warm": true}`; with a raising `restart` → 502 OpenAI shape.
   - warm-up failure (monkeypatch `warmup.run` to return False) → 503 + `Retry-After`.
5. Do not edit `app/engine.py`, `app/warmup.py` or fixtures.
