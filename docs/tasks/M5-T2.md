## Context

Encode SPEC §13 as executable checks against the fake engine and a temp data dir. Hardware- and
deployment-dependent criteria get explicit `pytest.mark.skip(reason=...)` naming the blocker
(Q-001 / M0), so the suite is honest about what is unverified.

## Steps

1. Use `client`, `library`, `store`, `fake_engine` fixtures where possible; build extra apps with
   `create_app(Settings(..., api_keys=..., studio_auth=...))` for auth checks.
2. Tests:
   - WAV: `POST /v1/audio/speech` with `model=tts-1`, `voice=ashley-en` → RIFF, header rate 48000,
     `float(X-RTF) <= 0.2`.
   - Streaming: `stream=true&response_format=pcm` first chunk arrives within 300 ms (measure
     time-to-first-byte around the `client.stream` context), total decodes to ~0.6 s.
   - All eight imported voices: write 8 Qwen3-style safetensors into `settings.import_dir`, call
     `/api/voices/import`, then synth each name in its language (en/ja/ko/zh mapping) → 200.
   - Warm start: after `TestClient` startup, `/ready` is 200 before any synthesis; `/health` 200.
   - Clone flow: upload 6 s WAV → voice appears in `/api/voices` and `/v1/audio/voices`, then synth
     by name over `/v1` → 200.
   - Design flow: `/api/design/candidates` with n=3 → select candidate → `/api/design/save` → new
     voice in `/api/voices` and usable over `/v1`.
   - Concurrency: with `engine_concurrency=2, max_queue=16`, fire 20 `POST /v1/audio/speech` calls
     from a thread pool; assert every response is 200 or 429, at least one 429 occurs, and every
     429 carries `Retry-After`.
   - Errors: unknown voice 400 lists names; 4001-char input 400; bad key 401; unknown take 404.
   - Auth: `API_KEYS` guards `/v1/*` but not `/health`/`/ready`; `STUDIO_AUTH` guards `/api/*` and
     `/` (401 with `WWW-Authenticate: Basic`).
   - UI assets: `/` is HTML referencing `studio.css`, `/static/js/core.js` returns JS.
   - Skipped with reasons: VRAM ≤ 10 GB and card sharing (needs `nvidia-smi` on the host);
     LiteLLM/Open WebUI/Hermes/Wyoming unchanged (external clients); listening spot-check of the
     eight voices (human); container build (CI `package`).
3. No sleeps longer than needed; poll with a deadline helper instead of fixed sleeps.

### Skipped (5) — exact reasons

1. `test_acceptance_vram_and_card_sharing` — VRAM ≤ 10 GB + whisper-stt/TEI card sharing need
   `nvidia-smi` on the 3090 host; unverifiable against the fake engine (Q-001 / M0).
2. `test_acceptance_external_clients_unchanged` — LiteLLM tts, Open WebUI, Hermes, Wyoming bridge
   are host-side deployments; verified unchanged at cutover (SPEC §11), not in pytest (Q-001 / M0).
3. `test_acceptance_voice_spot_check` — listening spot-check of the eight voices against the Qwen3
   versions requires a human listener.
4. `test_acceptance_container_builds` — container build is proven by the CI `package` job, not pytest.
5. `test_acceptance_ui_parity_and_keyboard` — visual parity with `ui/studio.html` and keyboard-only
   navigation need a browser; covered by the Playwright e2e suite.
