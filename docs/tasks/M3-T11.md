- **Milestone:** M3
- **Wave:** 10

## Context

Human decision (2026-11-02): Studio synthesis goes through `/api/speak` (Studio Basic auth), so the
browser never needs a `/v1` bearer key. `M2-T14` shipped:
- `POST /api/speak?save=false` → audio in `response_format`, no take, `X-Voice`/`X-Sample-Rate`.
- `TakeInfo.format` records the requested container.
- `GET /api/takes/{id}/audio?format=…` transcodes for playback/download.

## Steps

1. `clone.js` "Test a line":
   - POST `/api/speak?save=false` with `{model:"voxcpm2", voice: name || "ad-hoc", input:
     SAMPLE[language], response_format: "wav", ref_audio: dataUri, ref_text: ...}`.
   - Remove the `api_keys_required` gating and its hint/`aria-describedby`; keep the
     `state.engine?.stt` gating for auto-transcribe only. The button must be enabled whenever a
     file is present (WAV preview needs no bearer key).
2. `speak.js` / `index.html`:
   - Remove `disabled` from `#fmt`; toggle it only while streaming is on (streams are PCM), with
     the hint "Streaming uses PCM at 48 kHz" shown in that state. When off, Format applies.
   - Generate (non-stream) sends `response_format` from `#fmt`; on `TakeInfo`, play/download via
     `${take.audio_url}?format=${take.format}` (and `sample_rate` unchanged).
   - Take rows use `take.format` for their Play/Download links; the waveform still uses
     `wave_url`.
   - Streaming keeps `sample_rate: 48000` and PCM playback.
3. Tests:
   - `tests/test_ui_assets.py`: assert clone posts to `/api/speak?save=false`, no
     `api_keys_required` gating string remains, `#fmt` is not `disabled` in markup, the stream
     toggle disables it, and take URLs append `?format=`.
   - `tests/e2e`: update the Clone test to click "Test a line" (fake engine accepts ad-hoc
     `ref_audio`; assert no error and that the audio request hit `/api/speak?save=false`), and add
     a second app configuration with `API_KEYS` set where Test-a-line still works without a bearer
     key. Update any assertion that expected the button disabled.
4. Do not edit Python or other screens.
