## Context

`app/warmup.py` is a skeleton and `app/main.py` already creates it in the lifespan, starts
`run_forever()` in a background task, and `/ready` reads `warmup.warm` (`app/routers/system.py`).
Implement the warm-up: one non-streamed WAV synth + one fully-consumed stream, using the first
library voice or `app/assets/warmup.wav` when the library is empty. Only after both succeed set
`warm=True`; on failure set `last_error` and leave `warm=False`.

## Steps

1. `WarmupService.run() -> bool`:
   - resolve reference: `store.list()[0]` → `store.data_uri(key)` + `ref_text`; else read the asset
     (`settings.asset_dir / "warmup.wav"`) and data-URI it with `audio.read_audio_file`.
   - `engine.synth(SynthParams(text="Warm-up.", ref_audio=uri, ref_text=text, fmt="wav"))`.
   - consume `engine.stream(SynthParams(..., fmt="pcm", stream=True))` to completion.
   - success → `warm=True`, `last_error=None`, return True. Any exception → `last_error=str(exc)`,
     `warm=False`, log warning, return False.
2. `run_forever()`: loop until cancelled — `await engine.wait_ready(settings.warmup_timeout_s)`;
   if not ready, set `last_error`, `await asyncio.sleep(2)`, continue; try `run()`; break on
   success; on failure sleep 2 s and retry (bounded backoff via sleep, never a tight loop).
3. `app/main.py`: keep the scaffold's `create_app`/lifespan shape but make sure
   - the warm-up task starts after `engine.start()`;
   - shutdown cancels the task and awaits it (`contextlib.suppress(asyncio.CancelledError)`) before
     `engine.aclose()`;
   - the import-on-start call is unchanged; failures never block startup.
   You may adjust only `app/main.py` and `app/warmup.py` (no other paths).
4. `tests/test_warmup.py`:
   - `WarmupService(...).run()` against `fake_engine` returns True and `fake_engine.state["calls"] >= 2`
     (one WAV + one stream), `warm is True`.
   - empty library uses `app/assets/warmup.wav` (assert the request `ref_audio` starts with `data:`).
   - failure (engine_url at a closed port) → `run()` False, `last_error` set, `warm` False.
   - `TestClient(create_app(settings))`: poll `/ready` for ≤ 5 s → 200; `/health` 200 throughout.
   - `/ready` before warm-up (call `system.ready` with a WarmupService that is not warm via a tiny
     app or by checking the response when `run()` is monkeypatched to fail) → 503 + Retry-After.
