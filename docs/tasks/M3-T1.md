## Context

`ui/studio.html` + `ui/tokens.css` are the visual reference and read-only. `app/static/tokens.css` is
already an exact copy of the tokens. Build the real shell by porting the reference markup and CSS,
then split behaviour into ES modules. Other wave-3 tasks own `speak.js`, `voices.js`, `clone.js`,
`design.js`, `engine.js`; they rely on the element IDs and `core.js` exports in
`docs/CONTRACTS.md` §7 — do not rename them.

Port every screen's static structure (header, 5 tabs, Speak, Voices, Clone, Design, Engine) with
sample data replaced by empty containers. Keep the reference classes and CSS rules; move the inline
`<style>` into `studio.css` and trim it to what is used. Zero radius, one accent, lines not cards.

## Steps

1. `tests/test_ui_assets.py`: read `index.html`/`core.js` and assert
   - title "Voice Studio", red mark, live `#engine-status`, 5 `.vs-tab[data-tab]` and 5
     `.vs-screen` ids `screen-speak|voices|clone|design|engine`;
   - every element ID from `docs/CONTRACTS.md` §7 exists;
   - `tokens.css` + `studio.css` are linked and all 5 screen modules are referenced;
   - `core.js` exports `api`, `state`, `loadVoices`, `refreshEngine`, `registerScreen`,
     `selectVoice`, `wavePath`, `renderWave`, `play`, `showError`, `clearError`, `formatLang`;
   - `wavePath` produces a filled path for 72 amps (run it with `node -e`? keep it text-based:
     assert the function exists and the reference algorithm is present).
2. `index.html`: port the reference structure. Include all IDs from the contract. Add
   `<p class="vs-error" id="<screen>-error" role="alert" hidden></p>` above each action row.
   Empty: `#voice-chips`, `#takes-list`, `#voice-rows`, `#candidates`, `#engine-stats`.
   Keep the clone side notes, endpoint example placeholders, static tag buttons (`+ calm` …).
   Script tags: `<script type="module" src="/static/js/core.js">` then one per screen module.
3. `studio.css`: reference CSS + `.vs-error` (accent text, 12 px, no color-only signalling),
   `[hidden]{display:none!important}`, table/empty-state helpers. Keep `@media
   (prefers-reduced-motion: reduce)`.
4. `core.js`:
   - `api.get/post/patch/del` parse JSON, throw `Error(error.message)` on non-2xx;
     `api.postForm` for `FormData`.
   - `refreshEngine()` GET `/api/engine`, sets `state.engine`, updates `#engine-status` text to
     `Ready · <gpu>` / `Warming up…` / `Not ready · <reason>` (text, never color alone).
   - `loadVoices()` GET `/api/voices`; `selectVoice(name)` persists `localStorage["vs.lastVoice"]`.
   - `registerScreen(name, {init, show})`: run `init` once after DOMContentLoaded; switch screens by
     hash (`#speak` default), set `aria-current="page"`; call `show` of the active screen. Header
     engine status refresh every 10 s.
   - `wavePath(amps)` copied exactly from `ui/studio.html`; `renderWave(svg, amps, current)` sets
     `path d` and toggles `is-current`.
   - `play(url)` single shared `Audio` element (toggles), `stopAudio()`.
   - `showError(screen, message)` / `clearError(screen)`; `formatLang(code)`.
   - No `innerHTML` with API/user text; create nodes + `textContent`.
5. `app/main.py` already serves `/static` and `/`; do not edit it.
