## Context

Wave-3 review found UI↔API drift and lifecycle bugs. Contracts now expose `VoiceSummary.key`
(use it for URLs/voice parameter; `name` is display only) and `EngineStatus.stt` /
`EngineStatus.api_keys_required`. `SpeechRequest.input` is capped at 4000 chars server-side.

## Steps

1. **voice keys** — in `speak.js` and `voices.js`, use `voice.key` for: chip selection + `/api/speak`
   `voice`, `/api/voices/{key}` PATCH/DELETE, `/api/voices/{key}/audio`; keep `voice.name` for
   display text. `state.selectedVoice` stores the key; revalidate it in `show()` against
   `state.voices` (fall back to the first key) so a deleted/renamed voice cannot be posted.
2. **rename field** — `voices.js` inline editor must send `{name: newName}` (not `new_name`) plus
   `language`/`ref_text`; it must also validate the new name against `^[a-z0-9][a-z0-9_-]{0,63}$`
   and show the reason inline. Focus the confirm Delete button when the confirm row opens.
3. **speak lifecycle** — stop awaiting the playback tail in `generate()`: re-enable the button and
   `loadTakes()` as soon as the response stream ends, while scheduled audio keeps playing. Close the
   `AudioContext` and cancel the body reader in `finally` on every path. Revoke object URLs in
   `stopAudio()`/before creating a new one. While the stream toggle is on, disable `#fmt` (streaming
   is PCM) and restore it when off.
4. **clone** — call `updateSave()` in *all* file-probe failure branches; guard Save against
   double-submit (`disabled` + in-flight flag, restore in `finally`); set
   `#auto-transcribe.disabled = !state.engine?.stt` on `show()`; set
   `#test-line.disabled = !!state.engine?.api_keys_required` with a `title` explaining that Test a
   line needs `/v1` access (Q-023); remove the dead `api.get("/api/engine")`; remove the 800 ms
   forced navigation. Add a neutral `<p class="vs-status" id="clone-status" role="status">` to
   `index.html` and use it for "Voice saved." (keep errors in `#clone-error`).
5. **design** — `show()` calls `loadVoices()` so duplicate-name validation works on a deep link.
6. **engine** — keep the current stats; add the reference sub-lines where the data exists only
   (KV cache "Max 2 concurrent requests", RTF "Non-streamed WAV", First audio "Streamed PCM, warm",
   Runtime); do not invent values.
7. **tests** — extend `tests/test_ui_assets.py`: `node --check` every `app/static/js/*.js` (skip if
   node is missing), and assert every `import { … } from "./core.js"` name exists as an export in
   `core.js`. Add assertions for `key` usage, `{name:` rename body, `stt`/`api_keys_required`
   gating and the `#clone-status` element.
8. Do not edit Python code or module ownership beyond the listed files.
