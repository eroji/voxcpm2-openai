## Context

Implement `/api/speak`, `/api/takes*` using `SpeechService` and `TakeStore`. Read
`docs/CONTRACTS.md` §2 and §4. `TakeStore.create(..., take_id=...)` and `.new_id()` exist so a
streamed response can advertise `X-Take-Id` before the audio is complete.

## Steps

1. `POST /api/speak` (body `SpeechRequest`):
   - Non-stream: synthesize WAV internally (copy the request with `response_format="wav"`), save the
     take via `takes.create(samples, rate, voice=result.voice, text=input, language=<voice lang or
     "">, rtf=..., first_audio_ms=...)`, then if the client asked for another format transcode the
     saved samples with `audio.transcode(..., speed=1.0)`. Response `TakeInfo` with
     `audio_url`/`wave_url` from `takes.take_urls(id)`.
   - Enforce `len(input) <= settings.max_input_chars` (400) like `/v1`.
   - Stream: `take_id = takes.new_id()`, `streaming = await speech.stream(payload)` (admission
     raises 429/503 before headers); wrap the chunk
     iterator in `try/finally: await streaming.aclose()`: collect s16le bytes, yield them unchanged,
     and when exhausted decode to float and `takes.create(..., take_id=take_id)`. Return
     `StreamingResponse(..., background=BackgroundTask(streaming.aclose))` with `X-Take-Id`,
     `X-Voice`, `X-Sample-Rate`, so a pre-first-chunk disconnect still releases the slot. Decode only complete even-length PCM chunks (carry a 1-byte remainder).
   - Language: look up the resolved voice in `store` if it exists, else `""`.
2. `GET /api/takes` → `{"takes":[TakeInfo]}` newest-first (map dict + urls; skip entries whose WAV
   is missing). `GET /api/takes/{id}/audio` → `FileResponse(media_type="audio/wav")`.
   `GET /api/takes/{id}/wave` → `{"amps": takes.wave(id)}`. `DELETE` → `{"deleted": id}`.
3. `POST /api/takes/{id}/save-as-voice` body `SaveAsVoice`: read take WAV, `store.create(name, ...,
   ref_text=take["text"], language=payload.language, consent="own-generated-voice",
   source="uploaded")`; return `VoiceSummary`. Unknown take → 404.
4. Tests: non-stream speak returns TakeInfo and take audio is a WAV with matching duration; stream
   speak returns `X-Take-Id` and afterwards the take exists with the correct duration (poll); takes
   list newest-first; wave has 72 amps; save-as-voice creates a voice with the take text; delete;
   404s for unknown take in each route.
5. Do not edit `app/speech.py`, `app/store.py` or fixtures.

### Deviations / interpretations

- **Non-stream `response_format != "wav"`**: the brief's transcode step is meaningless if the
  response is always JSON, so non-wav formats return the transcoded audio bytes
  (`Content-Type` per `audio.mime_for`), while `wav` returns `TakeInfo`. This matches the merged
  UI (`speak.js playWhole` handles both a JSON and an audio non-stream response) and keeps the
  take on disk as WAV either way. Contract §2 lists `TakeInfo` for the default case.
- **Stream take decoding**: `pcm` streams are collected as s16le with the 1-byte carry (per brief);
  other streamed containers are decoded from the complete bytes with `audio.read_audio` at the end.
  If decoding fails (headers already sent), the router logs the take id only and skips the save.
- `BackgroundTask` imported from `starlette.background` — this FastAPI version does not re-export
  the singular form.
