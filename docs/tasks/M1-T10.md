## Context

Wave-4 review found:

- `SpeechService.resolve()` catches `VoiceNotFound` but `store.get("Ashley EN")` raises `BadRequest`
  (`invalid_voice_name`) because of the space, so an unknown/display-name voice is a 400 that does
  **not** list valid names (SPEC §6). Map any lookup failure to `BadRequest(... valid names ...,
  code="voice_not_found")`.
- `WarmupService.run()` is only tested with a dead engine, so the "WAV succeeds, stream fails"
  ordering (R-005: `/ready` only after **both**) is unverified; `run_forever`'s not-ready branch and
  `wait_ready` timeout are uncovered.
- `app/main.py` shutdown awaits the cancelled warm-up task; a non-`CancelledError` from
  `run_forever` re-raises out of lifespan.
- Q-014 says the asset fallback sends `ref_text="Warm-up."`, but the code sends `None`.

## Steps

1. `app/speech.py` `resolve()`: wrap `store.get()`; on `APIError` (BadRequest/NotFound) raise
   `BadRequest(f"Unknown voice '{request.voice}'. Valid voices: {names}", param="voice",
   code="voice_not_found")` where `names` comes from `store.list()` (keys). Keep ad-hoc `ref_audio`
   behavior unchanged.
2. `app/warmup.py`: asset fallback uses `ref_text="Warm-up."`; keep the two-request ordering.
3. `app/main.py`: wrap the shutdown `await task` in
   `contextlib.suppress(asyncio.CancelledError, Exception)` (the done-callback already logs).
4. Tests:
   - `resolve("Ashley EN")` where the voice exists under key `ashley-en` → 400 `voice_not_found`
     listing `ashley-en` (not `invalid_voice_name`).
   - Warm-up with `engine.open_stream` monkeypatched to raise → `run()` False, `warm` False,
     `last_error` set, and the WAV request was made first (assert call order).
   - `run_forever`: `engine.wait_ready` returns False → sets `last_error`, sleeps; cancel the task
     and assert it exits without raising (`asyncio.wait_for`).
   - Shutdown: a warm-up task that raised `RuntimeError` does not make the TestClient lifespan
     raise (build an app with a fake warmup/engine, or unit-test the suppress block).
   - Existing warm-up tests stay green; add a `FakeEngine` call log assertion that the second call
     had `stream: True` (extend `tests/fake_engine.py`? it is NOT in `owns:` — instead assert on
     `fake_engine.state["calls"]` plus a local wrapper that records `open_stream` calls).
5. Do not edit routers or fixtures.
