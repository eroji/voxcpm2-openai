## Report

### Files changed

- `app/static/studio.css` — added
  `button:disabled, select:disabled, input:disabled, textarea:disabled { opacity: .45; cursor: not-allowed; }`
  (no new colors; the `:focus-visible` 2 px ring rule is untouched).
- `app/static/index.html` — `#design-sample` now has `lang="ja"` (matches `ui/studio.html` L345);
  Q-024 Format hint kept as-is.
- `app/static/js/speak.js` — streaming requests send `sample_rate: 48000` explicitly
  (`if (stream) body.sample_rate = 48000;`); the 48 kHz `AudioContext`/s16le handling is unchanged.
  Without it a server with `SAMPLE_RATE ≠ 48000` would resample the PCM stream while the browser
  decoder stays at 48 kHz (`speech.stream` honors `request.sample_rate` first).
- `app/static/js/voices.js` — `#voices-count` shows `state.voices.length` (library total, SPEC §8);
  a filter that matches nothing now renders a "No voices match the current search or filter." row
  instead of a blank table.
- `app/static/js/design.js` — `#design-lang` change updates `#design-sample.lang`.
- `tests/e2e/conftest.py` — module-level `try: from playwright.sync_api import … except ImportError:
  raise RuntimeError("… .venv/bin/pip install playwright && .venv/bin/playwright install chromium")`;
  the `page` fixture's `importorskip` is gone (Chromium-missing still fails with the install command).
- `tests/e2e/test_studio.py` — module-level `importorskip` removed (plain import → collection error
  when Playwright is missing); added `test_speak_stream` (stream on by default, "slow" text,
  asserts `#generate` disabled → re-enabled, take row appears, no `#speak-error` — fake engine
  streams 10 PCM chunks) and `test_clone_save` (5 s WAV + name + consent → Save voice →
  "Voice saved." in `#clone-status` and `/api/voices` contains `e2e-saved`, cleaned up);
  `test_screenshot_390` parametrized over all five screens; `test_engine_screen` restart is now
  tolerant: accepts the 502 (`s6-svc` error visible) **or** a successful restart, asserts the button
  returns to "Restart engine" + enabled and `/api/engine` answers 200, and waits for re-warm —
  no `s6-svc` text assertion on hosts where restart succeeds.
- `tests/test_ui_assets.py` — five new checks: disabled CSS rule + focus ring kept,
  `lang="ja"` + design.js wiring, streaming `sample_rate: 48000`, voices count = library total +
  filtered-empty copy, and no `importorskip` anywhere in `tests/e2e/*.py`.
