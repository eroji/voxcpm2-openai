## Context

Implement `POST /api/voices/clone` (multipart) and `POST /api/transcribe` (multipart) in
`app/routers/studio_clone.py`, using `app/audio.py` and `app/store.py`. Read
`docs/CONTRACTS.md` §2, §4, §6. `STUDIO_AUTH` is enforced globally by middleware; nothing extra.

## Steps

1. Clone handler:
   - Form fields: `file: UploadFile`, `name: str`, `language: str`, `ref_text: str = ""`,
     `consent: str = ""`. Require consent exactly `"true"`/`"on"` (case-insensitive) else 400
     `consent_required`; require a non-empty filename and file.
   - Read at most `settings.max_upload_bytes + 1` and reject larger with 400 ("20 MB" in message).
   - Decode with `soundfile` via `audio.read_audio` (never trust extension/content type); decode
     failure → 400 `invalid_audio`.
   - Duration 3–30 s (`settings.min_ref_seconds`/`max_ref_seconds`) → else 400.
   - Normalize: mono (already), `trim_silence`, `peak_normalize(-1 dBFS)`; keep the original rate
     unless > 48 kHz then `resample` to 48 kHz. `store.create(name, samples, rate, ref_text=...,
     language=..., consent="uploaded-via-studio", source="uploaded",
     metadata={"original_filename": ..., "mime_type": "audio/wav"})`; duplicate → 409 (propagate).
   - Return `VoiceSummary` (`voice.summary()`).
2. Transcribe handler:
   - If `settings.stt_url` empty → 503 `APIError(503, "Transcription is not configured",
     code="stt_not_configured")`.
   - Read file (20 MB cap), POST `{stt_url.rstrip('/')}/audio/transcriptions` with
     `files={"file": (filename, bytes, content_type)}`, `data={"model": "whisper-1"}`, timeout 60 s,
     using `httpx.AsyncClient`. Non-2xx → 502 `APIError`; success → `{"text": body["text"]}`.
3. Tests use `client`, `store`, `settings`:
   - clone a 6 s WAV (`audio.wav_bytes`) → 200; store has the voice, consent normalized, duration
     3–30; duplicate → 409; 2 s and 31 s → 400; `consent` missing → 400 with `code=consent_required`;
     non-audio bytes named `.wav` → 400 `invalid_audio`; monkeypatch `settings.max_upload_bytes=1000`
     (restore afterwards) → 400.
   - silence trimming/peak: build audio with 1 s silence + 5 s tone + 1 s silence; assert stored
     duration < 7 s and peak ≈ −1 dBFS (read back via `store.read_audio`).
   - transcribe unset → 503. For the success path start a tiny uvicorn fake STT app in the test
     (thread, free port, `/audio/transcriptions` returns `{"text":"hello"}`), set
     `settings.stt_url=f"{url}/v1"`, post a file → `{"text":"hello"}`.
4. Do not edit `app/audio.py`, `app/store.py` or fixtures.
