- **requirements:** R-024, R-027, R-028, R-041, R-044, Q-006

## Context

Wave-5 review proved:
- Streamed `response_format=flac` (also possible for other ffmpeg-pipe formats) returns
  `X-Take-Id` but **never saves** the take: libsndfile cannot decode streamed FLAC, the router
  catches the exception and returns. SPEC §7 requires saving the take when the stream ends.
- Take `language` is looked up by display name (`ResolvedVoice.name`), so voices with
  `name != key` store an empty/wrong language.
- The internal WAV take inherits caller `sample_rate`/`speed`, so takes are not always 48 kHz
  (SPEC §5).
- `takes.wave()`/`store.list()`/`save_as_voice` run on the event loop.
- No `STUDIO_AUTH` test exists; `/v1/audio/voices` is not covered by the API-key test.
- The configured `max_input_chars` guard is untested (`SpeechRequest`'s 4000 cap masks it).

## Steps

1. `app/audio.py`: add `decode_any(data: bytes) -> tuple[np.ndarray, int]` — try `read_audio`, and
   on failure pipe through `ffmpeg -i pipe:0 -f wav pipe:1` then `read_audio`; raise
   `RuntimeError` with the ffmpeg stderr on failure. Use it for streamed take decoding.
2. `studio_takes.py`:
   - Language: resolve from the **request key** (`payload.voice`) via a helper that matches
     `voice.key == name` (fallback display match for backward compatibility); ad-hoc → "".
   - Internal synth: `model_copy(update={"response_format": "wav", "sample_rate": None,
     "speed": 1.0})` so the stored take is 48 kHz, unstretched.
   - Streamed take: on completion decode with `audio.decode_any` (works for flac/mp3/opus/wav/pcm);
     if decoding really fails, log and return (but add a test that all five formats save).
   - `X-Voice` uses `payload.voice` / an ASCII key, never a non-ASCII display name.
   - Move `takes.wave`, `store.list`, `store.read_audio`, `store.create` in save-as-voice to
     `asyncio.to_thread`.
3. Tests:
   - Voice with `name="Qwen A"`, `key="qwen-a"`, `language="ja"` (create via `store.create(...,
     key="qwen-a")`); non-stream and stream `/api/speak` → take language `ja`.
   - Stored take rate is 48000 even when the request asks `sample_rate=24000, speed=2.0`.
   - For each `response_format` in `pcm,wav,mp3,opus,flac` with `stream=true`, the returned
     `X-Take-Id` resolves to an existing take with duration ~0.6 s.
   - `settings.max_input_chars=10`, input 11 chars → 400 `code="input_too_long"` on `/api/speak`.
   - `tests/test_auth.py`: app with `studio_auth="u:p"` → 401 on `/`, `/api/voices`,
     `/static/js/core.js`; 200 with basic creds; `/health` and `/ready` open. App with
     `api_keys="k1"` → `/v1/audio/voices` 401 without bearer, 200 with.
4. Do not edit speech/engine/v1/store or fixtures.
