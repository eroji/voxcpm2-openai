## Context

`index.html` (M3-T1) contains the Speak screen with the IDs in `docs/CONTRACTS.md` §7; `core.js`
exports `api`, `state`, `loadVoices`, `registerScreen`, `selectVoice`, `renderWave`, `play`,
`showError`, `clearError`, `formatLang`, `fmtDuration`, `fmtClock`. Implement the screen module only
(no HTML/CSS edits). Use `textContent`, never `innerHTML` with API/user text.

## Steps

1. `VS.registerScreen("speak", { init, show })`:
   - `init`: `await loadVoices()`, render chips into `#voice-chips` from `state.voices` (name +
     uppercase language label), restore `localStorage["vs.lastVoice"]` else first voice, bind chip
     clicks (single-select, `aria-pressed`), bind `#generate` click and Ctrl/Cmd+Enter on
     `#speak-text`, keep CFG/steps readouts in sync with the range inputs (copy the reference
     behaviour), bind stream toggle (`aria-pressed`), bind `#fmt` select.
   - `show`: `loadTakes()` and `loadVoices()` refresh; render `#takes-list`.
2. Generate (`#generate`):
   - Disable button, text "Generating…"; clear error.
   - Build `{model:"voxcpm2", voice, input: #speak-text.value, instructions: #speak-style.value ||
     undefined, cfg: +cfg, steps: +steps, response_format: fmt, stream}` where `fmt` maps
     `#fmt` option values (`wav|pcm|mp3|opus`) and `stream` is the toggle.
   - **Streaming**: POST `/api/speak` with `response_format:"pcm"`, `stream:true`, read
     `res.body` chunks, decode s16le (carry odd byte), schedule via one `AudioContext` at 48 000 Hz
     (`createBuffer(1, n, 48000)` + `copyToChannel`), starting on the first chunk. On completion
     reload takes, re-enable button. On error read the JSON error message → `showError`.
   - **Non-stream**: POST `/api/speak`; on 200 create an object URL from the blob and `play()` it;
     prepend the returned TakeInfo.
   - Finally restore button text/enabled in `finally`.
3. Takes list: for each take render voice, `duration_s · RTF · first_audio_ms` stats, `fmtClock`
   time, text clamped to 2 lines, play button (`play(audio_url)`), an `<svg class="vs-wave"
   viewBox="0 0 300 24" preserveAspectRatio="none">` with a path filled by
   `renderWave(svg, amps, index === 0)` after GET `wave_url`, plus Download (anchor to `audio_url`
   with `download`) and Save as voice (`prompt("Voice name")` → POST
   `/api/takes/{id}/save-as-voice` with `{name, language: take.language || "en"}` → reload voices).
4. Empty takes: leave the list empty (no fake rows). Inline API errors above the action row via
   `showError("speak", message)`.
