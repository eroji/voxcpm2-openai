## Context

`index.html` has the Engine screen with `#engine-stats`, `#run-warmup`, `#restart-engine`,
`#engine-endpoint`, `#engine-error`; `core.js` exports `api`, `refreshEngine`, `showError`,
`clearError`, `registerScreen`, `state`.

## Steps

1. `registerScreen("engine", { init, show })`: `init` binds buttons; `show` calls `refresh()`.
2. `refresh()`: GET `/api/engine`, store in `state.engine`, render the 8 stats into `#engine-stats`
   as `.vs-stat` blocks: Model (`model`), GPU (`gpu` or "Unknown"), VRAM in use
   (`vram_used_mb` → `x.x GB` of `vram_total_mb`), KV cache, Warm RTF (`rtf` 2 decimals or "—"),
   First audio (`first_audio_ms` → `NNN ms` or "—"), Voices (count + "languages" count distinct),
   Runtime (`runtime`). Use `textContent`.
3. Refresh every 5 s **while visible**: a module interval that skips when
   `document.getElementById("screen-engine").hidden` is true. Clear the interval if the element is
   removed.
4. Run warm-up → POST `/api/engine/warmup`; disable button, text "Warming up…", restore in
   `finally`, refresh on success; errors inline.
5. Restart: first click changes the button to "Confirm restart", second click within 5 s POSTs
   `/api/engine/restart` (text "Restarting…", disabled), then refresh; cancel restores the label.
   No `confirm()`.
6. Endpoint example: set `#engine-endpoint pre` text to the real origin
   (`location.origin`) + `/v1/audio/speech` and a sample JSON body using the first voice name from
   `state.voices` (fallback `ashley-en`); keep it plain text.
