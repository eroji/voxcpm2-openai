How cloning works

1 The clip and transcript are stored with the voice and sent as ref_audio and ref_text on every request. Callers pass only the voice name.

2 An accurate transcript gives the highest similarity. Without one, VoxCPM2 falls back to reference-only cloning.

3 Existing Qwen3 voices import directly: their stored audio and transcript carry over.

Add a language

Only languages the engine supports are listed. The list comes from the backend, so a different model changes what you can add.

What a language controls

1 The tag on each voice, and the language filters in Voices.

2 The choices in Clone and Design.

3 Which test phrases Speak and Design offer. A new language starts with none until you add them.

4 Not how a voice sounds: VoxCPM2 reads the language from the text, so any voice can speak any supported language.
